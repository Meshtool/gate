# Gate

**The front door every AI helper walks through, so you always know who got in and what they were allowed to do.**

Think of it as a security desk in a building lobby. Before an AI helper can touch your projects, memory or tools, the Gate checks who it is and what it's allowed to do, lets it into only those rooms, and writes down every visit.

## What it does

- Checks every AI helper's identity before letting it in.
- Lets it do only what you allowed: which tools, how much spending, and for how long.
- Keeps a written record of every visit.

## What it won't do

- Let a helper do more than it was allowed.
- Let anyone skip the door.
- Use a password or key nobody handed it.

## Status

The Gate is running and protects Meshtool's own systems today. This repo is its public home page. The code is kept private while it's hardened, because security code gets the most careful review before it goes public.
